O Agendador de Horários é uma aplicação back-end desenvolvida em Java com Spring Boot, criada para gerenciar o cadastro e a consulta de horários de forma organizada e eficiente.

O projeto disponibiliza uma API REST utilizando Spring Web, com persistência de dados realizada por meio do Spring Data JPA, garantindo uma integração simples e performática com o banco de dados H2, 
utilizado em memória para facilitar testes eo desenvolvimento da aplicação.

A aplicação segue uma arquitetura em camadas (Controller, Repository e Model), promovendo melhor organização do código, facilidade de manutenção e maior escalabilidade.
Para reduzir código repetitivo e aumentar a produtividade, foi utilizado o Lombok, simplificando a criação de classes e métodos padrão.

Este projeto tem como objetivo principal consolidar conhecimentos em desenvolvimento back-end com Java e Spring, sendo ideal para fins de estudo, portfólio e demonstração de boas práticas no desenvolvimento de APIs REST.

🧠 Funcionalidades

✅ Cadastro de horários
✅ Listagem de horários agendados
✅ Persistência de dados com JPA
✅ API REST utilizando Spring Web
✅ Banco de dados em memória (H2)
✅ Redução de boilerplate com Lombok
